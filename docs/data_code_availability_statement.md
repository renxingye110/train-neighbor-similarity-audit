# Data and code availability statement

## Suggested manuscript text

Code, processed result tables, figure source data, and supporting reproducibility files for this study are available at https://github.com/renxingye110/train-neighbor-similarity-audit. Raw third-party peptide and protein sequence records should be obtained from the original public databases cited in the manuscript and are not redistributed here. The repository provides the current Figure 1-3 source data, the train-fold-only PCA development profile, the complete eight-endpoint validation screen, Supplementary Tables S1-S6, retained-set counts, protocol checks and scripts for reproducing the reported summaries and figures. Full model retraining requires the original third-party data and locally generated embeddings and is not reproduced from the archived package alone. The latest versioned public release is archived under the Zenodo concept DOI https://doi.org/10.5281/zenodo.20842728.
