# Legacy repository materials

This directory contains files from earlier manuscript versions that are not part of the current release.

The current manuscript is the cross-task similarity-stratified retraining sensitivity study. Legacy materials include the former source-held-out Figure 2 layout, the former candidate-prioritization Figure 3, earlier supplementary tables, and extension summaries that are not cited by the current main text or Supplementary Tables S1-S5.

They are retained for provenance only and should not be used to reproduce the current manuscript.
